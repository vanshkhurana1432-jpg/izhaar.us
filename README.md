# Izhaar — Where Feelings Find a Home

A free, anonymous peer-support community website.

## Deploy to Vercel

### Option 1 — Vercel CLI
```bash
npm i -g vercel
vercel
```

### Option 2 — Vercel Dashboard (no CLI)
1. Zip this folder and go to [vercel.com/new](https://vercel.com/new)
2. Drag and drop the zip, or connect your GitHub repo
3. Click **Deploy** — no build settings needed

## Project Structure
